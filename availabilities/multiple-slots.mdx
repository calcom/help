---
title: "Multiple time slots per day"
---

Use multiple time ranges to define separate periods of availability on a day.

1. Open **Availability** and select a schedule.
2. On the day you want to update, select **Add new time slot**.
3. Set the start and end time for each range. Repeat to add more ranges.
4. To reuse a day's ranges, select **Copy times to**.
