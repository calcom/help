---
title: "Link Specific Checking for Conflicts"
description: "Choose which calendars block a booking link and, for eligible organizations, consider only that link's bookings."
---

By default, Cal.com checks your selected calendars and your Cal.com bookings when determining availability. Bookings on one link can block the same time on your other links.

You can change which calendars a link checks. Eligible organizations can also choose to consider only that link's Cal.com bookings. These are separate settings.

## Choose which calendars a link checks

Use link-specific calendar conflict checking to choose which connected calendars block time on a particular link, instead of using your account-level selection.

1. Open **Links** and select the booking link.
2. Select **Availability**.
3. Under **Check for conflicts**, switch the dropdown from **Account** to **Link**.
4. Select the calendars you want this booking link to check for conflicts.
5. Click **Save**.

This way, you can fine-tune availability logic for each booking link individually. For example:

- For a **personal coffee chat** event, only check your personal calendar.
- For a **sales demo** event, only check your work calendar.
- For a **VIP booking link**, check both but ignore shared team calendars.

Calendar selection is available for individual booking links. Team booking links use each assigned team member's calendar conflict settings.

<Note>
  Choosing different calendars does not, by itself, stop your Cal.com bookings on other links from blocking this link. To change that behavior, use **Consider only this booking link's bookings** below.
</Note>

## Consider only this booking link's bookings

Turn on **Consider only this booking link's bookings** when you want bookings on your other links to stop blocking availability on this link.

<Note>
  This setting is only available to organizations with at least **15 members**. If your account does not meet this requirement, the toggle is disabled and a warning explains why.
</Note>

### Enable the setting

1. Open **Links** and select the booking link.
2. Under **Policies**, select **Limits & buffers**.
3. Turn on **Consider only this booking link's bookings**.
4. Click **Save**.

### What still affects availability?

- Bookings on this link still count when checking for booking conflicts.
- Your availability schedule still determines when you can be booked.
- Your selected connected calendars are still checked for conflicts.

For example, a booking on Link A will no longer block Link B through Cal.com's booking-conflict check when you enable this setting on Link B. A busy event on a calendar that Link B checks can still make that time unavailable.

<Warning>
  This setting can allow overlapping bookings across different links. It does not make time available outside your schedule or turn off connected-calendar conflict checking.
</Warning>
