---
title: "How to set up a link to receive payments from Stripe"
---

Cal.com uses Stripe and other apps to allow you to receive payments when someone books your paid link.

To start taking Stripe payments, please follow these steps:

1. Go to the Cal.com app store -> cal.com/apps
2. Search for Stripe using the Cal.com's app store search and install the app
3. Go to the **Payments & Seats** settings of your link
4. Select Stripe as the method and set the Stripe price and refund policy
