---
title: Minimum notice
---

Set a minimum notice to control how far in advance bookers need to schedule.

1. Open **Links** and select the booking link.
2. Choose **Limits & buffers**.
3. Under **Minimum notice**, enter a value and choose minutes, hours, or days. Cal.com uses whichever is higher: this booking link's value or the schedule minimum.
4. Select **Save**.

<Frame>
  <img src="/images/min-notice/minimum-notice.png" alt="Minimum notice set to two hours in link limits" />
</Frame>

For example, if someone wants to book a meeting tomorrow at 5:00 PM and the minimum notice is 120 minutes, they need to submit the booking by 3:00 PM tomorrow.
