---
title: "How to find your Link ID"
---

The Link ID is the number in the booking link's URL. You can use it with API v2, embeds, and support requests.

1. Open **Links** and select the booking link.
2. Choose **Setup**.
3. In the URL `app.cal.com/event-types/<ID>?tabName=setup`, find the number in place of `<ID>`.
