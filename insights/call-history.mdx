The **Call history** tab in [Insights](https://app.cal.com/insights/call-history) lists the calls made and received by your [Cal.ai](/cal-ai/cal-ai-help) phone agents.

Open it from **Insights** in the left sidebar, then select **Call history**.

## Columns

| Column | Description |
|---|---|
| Time | When the call took place |
| Duration | Length of the call |
| Channel type | How the call was handled, for example phone |
| Session ID | Unique ID of the call session |
| End reason | Why the call ended |
| Session status | Whether the call completed |
| User sentiment | How the caller came across during the call |
| From / To | The phone numbers on each side of the call |
| Call created | Whether the call was created successfully |
| Voicemail | Whether the call reached voicemail |

Use the search box to find a specific call, and **Display** to choose which columns to show.

If you have no calls yet, the page shows a **Create a Cal.ai Phone Agent workflow** button.
